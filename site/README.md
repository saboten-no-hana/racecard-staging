# 出資馬出走カードメーカー

一口馬主クラブの出資会員向けに、今週末に出走する出資馬を1枚の画像にまとめて、X（旧Twitter）に投稿できる形で書き出すツールです。

**https://saboten-no-hana.github.io/racecard/** （無料・登録不要）

- 複数クラブの出資馬を1枚に混在して並べられます（一口クラブ24クラブに対応。一覧と勝負服は `clubs.js`）
- 勝負服・競馬場とレース番号・レース名（重賞・リステッド・OP・条件特別は格つき）・発走時刻・コース・騎手・性齢・斤量を表示します（性齢・斤量は表示しない設定も可）
- 木曜の出走確定（枠順未定）の時点でも、金曜以降の枠順確定後（枠色つき馬番）でも使えます
- 日付ごとに 関東主場 → 関西主場 → 第3場 の順、その中はレース番号順に並べます（発走時刻順・入力順も選べます）
- 口取りの 当選／抽選待ち／落選 を表示できます
- 出走取消・競走除外になった馬は「出走取消」「競走除外」と表示されます（そのまま載せるか、削除するかを選べます）
- 背景は 芝・ダート・ナイター・白・G1・春・夏・秋・冬 と、色や画像を指定できるカスタム
- サイズは 縦長（幅1080、頭数に合わせて縦に伸びる）・正方形（1200×1200）・横長（1600×900から、16:9に近い形のまま広がる）
- 「X(Twitter)に投稿」「画像を保存」「画像をコピー」で書き出せます。投稿文には「出走一覧を入れる」で「東京11R 馬名」の一覧を入れられます（Xの文字数も表示）
- 入力内容はブラウザ内（localStorage）にだけ保存され、どこにも送信されません
- スマホのホーム画面に追加してアプリのように使えます（一度開けば、電波がなくても前回の内容で画像を作れます）

## 使い方

1. 「今週の出走馬から選ぶ」で、クラブや馬名（ひらがな・カタカナの一部でも可）で探して「追加」します。全項目が自動で入ります
2. ☆を押して★（出資馬）にしておくと、次に出走する週に「★の出資馬が今週N頭出走します［まとめて追加］」と出ます
3. 一覧にない馬（地方・海外遠征、個人馬主など）は「＋ 馬を追加」で手入力します。一覧にないクラブや個人馬主は「その他」を選び、「勝負服を設定」で勝負服を入れます
4. 口取り・写真・タイトル・デザイン・サイズを整えて、「画像を保存」または「X(Twitter)に投稿」

- 追加した馬は、ページを開くたびに最新の出馬表で更新されます（枠・馬番・騎手・発走時刻・取消など）
- 出資馬の名前をまとめて★にするには「馬名をまとめて★を付ける」に馬名を書くか、出資馬の一覧が載ったページの文字を貼り付けます（カタカナの馬名を拾い出します。外部サイトへのアクセスはしません）。今週の出馬表にいない馬は「出走待ち」として名前で覚えておき、出走する週に自動で★に変わります
- Android で「X(Twitter)に投稿」から X を選んでも投稿画面にならない時は、X アプリを一度終了（最近使ったアプリの一覧から閉じる）してから、もう一度押してください（X アプリがバックグラウンドで開いていると、共有を受け取らないことがあります）
- ★は端末ごとに保存されます。別の端末へは「★を他の端末に引き継ぐ」のコード・リンク・QRコード（スマホのカメラで読み取り）で移せます
- 「今週の出走馬から選ぶ」の上に、出馬表の状態（出走確定の発表待ち・馬番の発表待ち・確定済みなど）と、次に何がいつ載るかが出ます
- レースが終わった週の馬は「先週までの馬が残っています［消す］」で片付けられます

## 今週の出走馬の自動取得

`.github/workflows/fetch-races.yml` が JRA ホームページの出馬表を読み、一口クラブ名義の出走馬だけを `data/races.json` に保存します。

| 時刻（日本時間） | 内容 |
|---|---|
| 毎日 15:45〜（13:45 起動） | 新しい開催日の出走確定（馬番なし）を確認（16時前に載ることもあるので早めに見る）。木曜は 18:30 まで5分おきに待ち、揃うまで取り直す |
| 木曜 19:05 | 安全網として1回取得（有馬記念の週の枠順抽選もここで拾う） |
| 毎日 10:05〜12:00（08:45 起動） | 翌日の枠・馬番を確認して取得 |

- GitHub の定期実行は30〜50分ほど遅れて起動することがあるので、確認を始める時刻より早めに起動して待ちます（待っている間は JRA にアクセスしません）

- JRA の発表（木曜16時すぎ・レース前日10時すぎ）から20〜30分ほどでページに反映されます
- 個人馬主の名前は保存せず、馬ごとに「どのクラブの馬か」だけを `data/cache.json` に記録して再利用します
- 出馬表全体は公開せず、一口クラブ名義の馬だけを載せます
- クラブ馬と記録した馬も、馬番が出た日に個別レースのページで名義を確かめ直します（クラブを離れて地方へ移り、中央に戻ってきた馬を載せないため）
- クラブ馬が最後に出馬表に載った日を `data/seen.json`（馬ID と日付だけ）に残し、90日以上空いたクラブ馬は馬番の出る前（木曜）にも馬のページで名義を確かめます
- 取得が止まった時（出馬表のページ形式が変わった、木曜に週末の出馬表を取れなかった ※年末年始を除く、通信エラーで一度も取れなかった）は Actions が失敗になり、GitHub からメールが届きます
- 各回の結果（クラブ別の頭数、一致しなかったクラブらしい名義、名義が変わった馬、リクエスト数）は、Actions の実行結果のページに要約が出ます

### 手動で取得する

GitHub のリポジトリで **Actions → 出馬表の取得 → Run workflow**（ブランチは main）を押すと取得します。取得の仕方は once（1回だけ）・confirm（15:45 から出走確定を見張る）・umaban（10:05 から翌日の馬番を見張る）から選べます。定期実行が遅れて起動しない時は confirm を使います。変更があれば `data/` がコミットされ、数分でページに反映されます。

## 開発メモ

- 画面は `index.html`、出走カードと（今後の）結果カードで共通の画像描画の部品（勝負服・配色・段組み・1行の描き方など）は `card-core.js`（外部ライブラリなし）。QRコードの生成は `qr.js`、ホーム画面用は `manifest.webmanifest`・`sw.js`（Service Worker。公開ページ＝https の時だけ登録）。ローカルでは `python3 -m http.server` で開けます
- テスト: `python3 -m unittest discover -s tools -p 'test_*.py'`（JRA にはアクセスせず、偽の出馬表ページで取得処理を確かめます。push のたびに `.github/workflows/test.yml` が実行）
- フォントや勝負服の画像を差し替えた時は、`sw.js` の `STATIC` の番号を上げます（保存済みのものを使い続けるため）
- OGP 画像（`og.png`）は `python3 tools/make_og.py` で作り直します（Playwright が必要。画面と同じ描画で、縦長のカードと作成ページを架空の馬名で描きます）。作り直したら `index.html` の `og:image` の `?v=` の番号を上げます
- クラブを追加する時は `clubs.js` にエントリを足し、勝負服画像のファイル名を `silks/sources.txt` に書いて push すると、`.github/workflows/fetch-silks.yml` が取得します

## 素材とライセンス

- 勝負服の画像は Wikipedia の各クラブ法人の記事に掲載されている Wikimedia Commons の画像（CC0）を `silks/` に保存して使っています。手描きの勝負服の形は、Commons の勝負服の標示の見本（CC0、`silks/examples/`）によります
- 写真は自分で撮影したものを使ってください。クラブ提供写真の転載は各クラブの規約を確認してください
- `og.png` は架空の馬名で作ったサンプル画像です（`tools/make_og.py`）

### フォント

画像の文字には [IPAexゴシック](https://moji.or.jp/ipafont/)（Version 004.01）を使っています。
IPAフォントライセンスv1.0 に従い、フォントファイルは改変せずに `fonts/ipaexg.ttf` として同梱しています。
ライセンス文書は `fonts/IPA_Font_License_Agreement_v1.0.txt` を参照してください。
